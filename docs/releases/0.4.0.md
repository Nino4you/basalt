# Basalt 0.4.0 — fourth preview

The desktop app now updates itself, and the Linux packages run on more distributions. **Still a
development preview, not a complete replacement for Obsidian.**

## New

- **Updates from inside the app (Linux and Windows):** when Settings → General finds a newer
  release, "Install and restart" saves every open note, downloads the package that matches how
  Basalt was installed (AppImage, `.deb` or Windows installer), checks its signature against the
  key built into the app and restarts into the new version. A `.deb` asks for the administrator
  password. Nothing is installed without pressing the button; the automatic check stays off by
  default. Android keeps announcing new releases with a download link.
- Releases carry `latest.json` and an updater signature (`.sig`) for every desktop package,
  signed with a dedicated updater key (see `docs/release-signing.md`).

## Changed

- **Linux packages run on older distributions:** they are built on Ubuntu 22.04 and need glibc
  2.35 or newer. The 0.3.0 `.deb` installed on Ubuntu 22.04 and Debian 12 but did not start
  there. Every build is now started on Debian 12, Ubuntu 24.04, Fedora 42 and Arch Linux before
  it is released.
- **Plugin catalog:** the "Checked" badge only appears for a plugin installed from the catalog's
  own repository, and only for the exact checked version; forks with the same plugin id no
  longer show it.

## Installation

- **Linux x86_64:** install the `.deb` with your package manager or make the AppImage
  executable.
- **Windows x64:** run `Basalt_0.4.0_x64-setup.exe`. The installer is not code-signed yet, so
  SmartScreen asks once ("More info" → "Run anyway"); check it against `SHA256SUMS` first.
- **Android (ARM64, x86_64):** install `Basalt_0.4.0_android-universal.apk` as an update over
  0.3.0.
- **Coming from 0.3.0 on the desktop:** install 0.4.0 by hand once. From then on, updates come
  through the app.
- **Verify:** see "Verifying downloads" in `docs/release-signing.md`.

## Known limitations

- Sync, pen/OCR and spreadsheet plugins have not yet been verified end to end on real devices;
  plugin tests mostly run in a browser harness.
- The in-app update was tested end to end with the AppImage; the `.deb` and Windows update
  paths get their first real run with the update after this release.
- No signed APT repository, not in F-Droid or Google Play yet (the listing is prepared in
  `fastlane/`, see `docs/distribution.md`).
- Plugin code runs unsandboxed in the main WebView. Only enable trusted bundles.
- Android SAF providers do not guarantee atomic file replacement.
- File recovery covers notes and canvases; backups of attachments still have to be restored by
  hand.
- Emulator and browser tests do not replace tests on real Android devices.
