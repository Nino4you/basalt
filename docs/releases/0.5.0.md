# Basalt 0.5.0 — tablets, Bases and more of your vault

A feature release: Basalt gets a layout of its own for tablets, reads Obsidian's Bases, embeds
parts of notes in the editor and accepts what other Android apps share with it. **Still a
development preview, not a complete replacement for Obsidian.**

## New

### Tablet layout

- **A floating dock** of icons replaces the desktop ribbon on tablets: a new-note button, the
  views of the left sidebar and the actions. It sits at the left edge, or as a pill at the
  bottom (Settings → Appearance → Tablet dock).
- **Rearrange it by dragging:** hold an icon until it lifts, then move it. With a mouse the
  desktop ribbon can be reordered the same way.
- **Sidebars float as cards** over the note, without dimming it. A tap beside a card closes it
  and still lands in the note. Cards follow the finger when dragged out or back. With the dock
  at the bottom, a card rises out of the icon that opened it.
- **Pin** a card to keep the sidebar beside the note while there is room.
- **Focus mode** hides everything but the note, on every layout.
- Larger touch targets throughout. On Android tablets the app now keeps clear of the system
  navigation bar, so the settings button and the status bar can be tapped again.

### Notes and vault

- **Bases:** `.base` files open as database views, shown as tables and cards with filters,
  formulas and sorting.
- **Embeds in the editor:** live preview shows image, media and note embeds. `![[Note#Heading]]`
  and `![[Note#^id]]` embed just that part, and images take a size such as `|300`.
- **Note composer:** merge a note into another one, or move a selection into a new note.
- **Pop-out windows:** open a note in a window of its own on the desktop.
- **Search operators:** `line:`, `section:`, `task:`, `task-todo:`, `task-done:` and `/regex/`.

### Android

- **Share to Basalt:** text, links, images and PDFs from other apps become a new note or are
  appended to the open one.
- **Updates install in the app:** Basalt downloads the new APK, checks that it is the right
  version and signed with the same certificate, and hands it to the system installer.

### Plugins

- Plugins can open views in the sidebars (`getLeftLeaf`, `getRightLeaf`, `ensureSideLeaf`),
  which many community plugins need.
- The plugin catalog lets you pick which release to install.
- Plugin settings are written once per burst of changes instead of on every keystroke.

## Installation

- **Linux and Windows with 0.4.x:** Settings → General → check for updates → "Install and
  restart".
- **Android with 0.4.x:** install `Basalt_0.5.0_android-universal.apk` as an update. From 0.5.0
  on, later updates install from Settings → General.
- **Linux x86_64 (new install):** install the `.deb` with your package manager or make the
  AppImage executable.
- **Windows x64 (new install):** run `Basalt_0.5.0_x64-setup.exe`. The installer is not
  code-signed yet, so SmartScreen asks once ("More info" → "Run anyway"); check it against
  `SHA256SUMS` first.
- **Verify:** see "Verifying downloads" in `docs/release-signing.md`.

## Known limitations

- The tablet layout and its gestures were tested in emulated touch browsers, not yet on real
  tablets.
- Sync, pen/OCR and spreadsheet plugins have not yet been verified end to end on real devices;
  plugin tests mostly run in a browser harness.
- No signed APT repository, not in F-Droid or Google Play yet (the listing is prepared in
  `fastlane/`, see `docs/distribution.md`).
- Plugin code runs unsandboxed in the main WebView. Only enable trusted bundles.
- Android SAF providers do not guarantee atomic file replacement.
- File recovery covers notes and canvases; backups of attachments still have to be restored by
  hand.
- Emulator and browser tests do not replace tests on real Android devices.
