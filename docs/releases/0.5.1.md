# Basalt 0.5.1 — plugin compatibility

A release for the plugin compatibility layer. **Still a development preview, not a complete
replacement for Obsidian.**

## Fixed

- **cmdr and Iconize together:** icons that a plugin registers without an `<svg>` wrapper (as
  `obsidian.d.ts` describes `addIcon`) are now drawn in a 100 × 100 box. Before, they were
  listed but could not be loaded, so Iconize stopped as soon as cmdr was enabled.
- **Copilot and Omnisearch start:** `registerObsidianProtocolHandler` was missing. Plugins now
  receive `obsidian://` links that are clicked inside Basalt; links from other apps do not
  arrive, because Basalt does not register the scheme with the system.

## Plugin compatibility

- Plugins get the host's own autocomplete, search, CodeMirror lint and Mermaid modules instead
  of failing on missing ones.
- Plugin settings can open real sub-pages, show grouped settings and interactive search
  fields; disabled controls, button tooltips and removing the highlighted button work.
- Plugin editors see the real live preview state, and plugins see the active theme.
- Dates are real shared Moment-style objects instead of plain timestamps.
- Plugin DOM helpers create real SVG elements.
- Older ES5 plugins load without replacing shared host classes and keep their lifecycle when
  they set loaded flags themselves; their text requests use the normal HTTP transport.
- Plugin embeds and code blocks refresh when background parsing catches up.

## Installation

- **Linux, Windows and Android with 0.5.0:** Settings → General → check for updates →
  "Install".
- **With 0.4.x:** Linux and Windows update from Settings → General; on Android install
  `Basalt_0.5.1_android-universal.apk` as an update.
- **Linux x86_64 (new install):** install the `.deb` with your package manager or make the
  AppImage executable.
- **Windows x64 (new install):** run `Basalt_0.5.1_x64-setup.exe`. The installer is not
  code-signed yet, so SmartScreen asks once ("More info" → "Run anyway"); check it against
  `SHA256SUMS` first.
- **Verify:** see "Verifying downloads" in `docs/release-signing.md`.

## Known limitations

Unchanged from [0.5.0](0.5.0.md#known-limitations). Plugins that need Node modules (`crypto`,
`os`, `https` …) or the CodeMirror 5 mode registry (for example Code Styler) still do not load.
